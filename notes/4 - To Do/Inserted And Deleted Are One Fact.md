# Inserted and deleted are one fact read from two ends

Noted 2026-08-14, while looking at UNANSWERED.

Which name an unanswered object gets depends only on the side it sits on:
output means it was made, input means it went nowhere. Swap which grid you call
the input and inserted becomes deleted, with nothing else changing.

Keep in mind when anything treats one of them as the special case.
