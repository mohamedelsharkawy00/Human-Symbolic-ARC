Custom ARC puzzles
=================

Enable CUS beside TRN / EVL / TST in the app. Disable the other datasets to
browse only these fixtures. Selection is saved between launches.

Add one ARC JSON file per puzzle in this directory, with `train` and `test`
arrays and inline `input` / `output` grids. The filename becomes its ID.
Files load alphabetically, ahead of competition puzzles when both are enabled.
Toggle CUS off and on to reload files (enable another dataset first if needed).

- `connectivity_stress_30`: corner gaps admit an 8-way outside flood. Red teeth
  amplify interior blue contour votes until they outnumber exterior black votes.
- `connectivity_control_30`: sealed corners; 4-way and 8-way floods agree.

Both are 30x30; their output recolors blue interiors yellow. Regenerate and
verify their standalone flood checks with `python tests/connectivity_stress.py`.

Movement examples
-----------------

Each puzzle has two training pairs and one test pair. Background is black (0),
and the object is red (2).

| Puzzle | Example | Expected movement (down, across) |
| --- | --- | --- |
| `movement_resize_stationary` | Add two background rows below an unchanged object. | `(0, 0)` |
| `movement_bidirectional` | Move the object two columns right. | `(0, 2)` from either search direction |
| `movement_rotation_control` | Turn an asymmetric object clockwise at the same top-left position. | `(0, 0)`, with object pose 3 |

Generate these files and check their geometry with
`python tests/movement_examples.py`. This checks the fixtures, not the solver.

`movement_stationary_filter` exercises movement agreement with multiple objects.
Two red objects move right three cells and become green; a blue object stays put,
and two background rows are added below. In reading 5 (connected monochrome,
Move + Color), both red input objects should support the same movement, while
the blue correspondence remains exact. The expected totals across the training
pairs are 4 exact, 8 recolored, 0 overlaps, and 0 unexplained cells. This fixture
is maintained directly and is not generated by movement_examples.py.
