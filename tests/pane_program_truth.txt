# Pane programs: the reading, said in the solver's own words, and RUN.
# Format:  <id>  <shape>, then the program, one SENTENCE a line, indented.
#   Prefix a line with WRONG to mark a known failure (not a regression).
#
# NOT WRITTEN BY HAND. Every program is what say_panes emits for that puzzle,
# taken off suggested_programs, run on the train pairs, then asked for the
# held-out TEST answer. All right, none wrong, nothing searched for.
#
# THE SHAPES, every one out of words that already existed:
#   AND           IntersectionList
#   OR            UnionList
#   NOR           UnionList, then AddColor + Colors to keep only what was filled
#   XOR           the union painted, then the intersection taken back out
#   PRIORITY      the winner painted, each loser laid under it in turn
#   AS THEY COME  the panes laid down in the order they were cut
# A pose, where the panes face each other rather than repeat, is said by naming
# the first pane's band, taking the others, and turning those.
#
# FOUR THINGS EVERY ONE OF THEM NEEDS, each of which cost a wrong answer first:
#   1. Origin. The panes are cut where they lie; without it they never stack.
#   2. A GET opening EVERY sentence. One starting with Colors carves what the
#      last sentence left instead of the input, and nothing reported it wrong.
#      sentence_with_no_source now refuses such a program before it is handed on.
#   3. A ground sentence last. Where the outputs elect no background the canvas
#      starts empty, the drawing comes out right, and the gaps stay transparent.
#   4. The ground FOUND, not assumed. "8 where no pane has anything, 0 else"
#      reads equally as NOR painting 8 and as OR painting 0; only the first is a
#      program, since painting the ground is not leaving it. The elected
#      background is tried first. Assuming it cost every NOR puzzle its sentence.
#   5. The hand said out loud before the paint. A paint lands only what is
#      marked, so a sentence that deleted its way down to what it wanted holds
#      nothing when it closes -- the seven NORs and the pane pick drew a blank
#      grid the day COMBINE began to read the mark. The pick drew nothing twice
#      over: Origin is an act, and an act on nothing picked leaves the pane
#      where it was cut. say_the_reading closes every sentence in one place now,
#      and says the hand there where the words have not left all of it marked.
#
# The programs run 7 to 42 ops. MAX_SEARCH_DEPTH is 32, so the six priorities
# are past what the search can reach at any budget; the rest are reachable in
# principle and were not reached in practice -- 0520fde7 is the only one of the
# 31 that had a saved solution before, at 4.59M attempts and 17.8s, and it is
# the one this replaces with zero attempts. What the search would do with the
# other 30 given time is NOT measured: no benchmark has been run against them.
