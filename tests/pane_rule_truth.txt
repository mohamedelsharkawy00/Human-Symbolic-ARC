# THREE RULES, and the stronger one is asked first.
#
# pane_mask_rule MAKES a drawing. At each position every pane is reduced to one
# bit -- something here, or ground -- and each pattern of those bits either
# paints a fixed color or copies one named pane. 2^k patterns, not 10^k colors.
# An AND is the all-bits pattern painting one color; a priority order is each
# pattern copying its leading pane. Neither has to be named to be found, and a
# pattern the pairs never showed is still one it can answer.
#   pose = the pose every pane after the first is read through, 0 = as is.
#          Panes facing each other across a wall are mirrored, not shifted.
#
# pane_pick_rule chooses one pane directly, or fits it behind the wall color.
# The ways are tried plainest first, a property before a place. Fitted picks
# prefer occupancy before palette: a sparse blueprint can also have an odd palette.
#
# pane_gather_rule keeps EVERY pane's drawing, cropped, and lays the drawings
# out the way the panes lie, any number each way, each cell as big as the
# largest drawing. Asked last.
