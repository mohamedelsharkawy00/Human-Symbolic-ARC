ARC Color Pair Test

Every color against every other. Each cell shows the column color as a mark sitting on the row color as background. Click a cell to cycle its verdict — does that pairing read right (foreground pops, background recedes)? First click = yes, second = no, third clears it. The diagonal (a color on itself) is skipped.
